Featured Projects

SYNTHIA — Deterministic World Simulation & Financial Intelligence Engine

C++ • Data Fabric • Deterministic Ingestion • Financial WorldState

SYNTHIA is a C++-first financial data and modelling platform that focuses on deterministic ingestion, provenance, and a knowledge-driven WorldState. It provides provider-neutral adapters (e.g., Yahoo, Finnhub) and a replayable ingestion session model. The project includes a headless C++ engine plus a lightweight web observatory for visualization.

Technical architecture

  • Core data and world state: C++ native engine
  • Ingestion adapters: provider-neutral FinancialDataSource implementations
  • FinancialDataFabric: validation, deduplication, provenance
  • Replayable ingestion sessions and a browser observatory (HTTP API)

How to run (from the repository)

cmake -S . -B build
cmake --build build -j2
./build/synthia_dashboard
# or run the finance ingestion CLI
./build/synthia_finance --provider yahoo --symbol AAPL --period 1d --record ingestion_session.json
