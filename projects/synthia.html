SYNTHIA — Deterministic World Simulation & Financial Intelligence

C++ • Data Fabric • Deterministic ingestion • Replayable sessions

Overview

SYNTHIA was designed as a headless-first data fabric and world-state engine. The core is a native C++ runtime that models entities, events, and knowledge with an explicit deterministic seed and replay model. The platform emphasizes provenance and reproducibility — ingestion adapters normalize provider observations and label them with freshness semantics.

Architecture Schematic

Key Components

  • Ingestion adapters: provider-neutral FinancialDataSource implementations (Yahoo, Finnhub) that produce normalized records.
  • FinancialDataFabric: validation, deduplication, timestamp/provenance handling, tagging of freshness.
  • WorldState (C++): deterministic state machine representing entities, observations, and knowledge graphs used for analysis and simulation.
  • Web Observatory: lightweight HTML/CSS/JS visualization that queries the core via HTTP/JSON endpoints for inspection and control.

Run & Development

cmake -S . -B build
cmake --build build -j2
./build/synthia_dashboard
# Record a polling ingestion session
./build/synthia_finance --provider yahoo --symbol AAPL --period 1d --record ingestion_session.json
# Replay an ingestion session
./build/synthia_finance --mode replay --replay ingestion_session.json

Engineering challenges & solutions

  • Determinism: Use of explicit seeds and ordered ingestion sessions to ensure replayable behavior for analysis and testing.
  • Provenance: Normalized records include source timestamps and provider metadata for traceability.
  • Performance: Native C++ data structures with careful memory management and batching on ingestion paths.
