# Docs

This folder contains site documentation, notes and a placeholder CV.

- Add a PDF named `CV.pdf` to this folder for the "Download CV" button to work.
- Add Markdown notes under `docs/notes/` for published engineering articles.

## How to update

To add a new engineering note:
1. Create `docs/notes/2026-10-article-title.md`
2. The file will be available on the site as a static document at `/docs/notes/2026-10-article-title.md`
