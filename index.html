Featured Projects

SYNTHIA — Deterministic World Simulation & Financial Intelligence Engine

C++ • Deterministic Ingestion • Financial WorldState • Data Fabric

SYNTHIA is a C++-first platform for ingesting financial observations, preserving provenance, and projecting normalized records into an explicit WorldState. It emphasizes deterministic ingestion and replay, making it suitable for reproducible analysis, simulation, and model laboratories.

Technical architecture

  • Native C++ engine (World / Physics / Agents / Knowledge)
  • FinancialDataSource adapters (Yahoo, Finnhub) with freshness semantics
  • Deterministic ingestion sessions & replay
  • Lightweight web observatory exposing native JSON & HTTP APIs

How to run

cmake -S . -B build
cmake --build build -j2
./build/synthia_dashboard
# or record a finance ingestion session
./build/synthia_finance --provider yahoo --symbol AAPL --period 1d --record ingestion_session.json
